# Pyramid Flow 

Repo for my university project to present the paper [Pyramid flow](("https://arxiv.org/pdf/2410.05954")

## Contents:

- `./Pyramid-Flow`: Submodule of the original pyramid flow github repo
- `./image.py`: Simple script to generate a video based on a simple wan model
- `./Notes.org`: General Notes of the original paper
- `./presentation.org`: The final presentation as required of my project

## Running:

To start the gradio runtime it is usually enough to run 
```sh
uv run app.py

```
withing the ./Pyramid-Flow subdirectory.

---

To start the presentation run the command

```sh
quarto preview presentation.qmd
```
This should start the web preview of the presentation.
